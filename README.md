# Misión Ergonomía

Juego web estático, responsive y accesible para reforzar decisiones preventivas básicas sobre ergonomía en contexto laboral.

## Archivos
- `index.html`: estructura de inicio, juego y resultados.
- `style.css`: diseño responsive, foco visible, modo oscuro y movimiento reducido.
- `script.js`: 6 retos, retroalimentación, puntuación, progreso y reinicio.
- `README.md`: documentación.

## Uso local y GitHub Pages
1. Sube estos cuatro archivos a la raíz de un repositorio de GitHub.
2. Abre `index.html` localmente para una prueba rápida.
3. Para publicar con GitHub Pages, configura Pages usando la rama y carpeta donde están estos archivos según la configuración vigente de tu repositorio.

No hay dependencias externas esenciales ni backend.

## Diseño de aprendizaje
Objetivo: identificar situaciones ergonómicas frecuentes y seleccionar una respuesta preventiva razonable. La secuencia usa situaciones, decisiones, retroalimentación inmediata y un compromiso de transferencia al puesto.

## Evaluación
Cada reto correcto suma 1 punto una sola vez. El porcentaje se calcula al final. Se utiliza **80 % como aprobación orientativa** y se recomienda refuerzo por debajo de **70 %** únicamente como supuesto pedagógico; no es criterio oficial. El resultado no sustituye evaluaciones, formaciones ni certificaciones oficiales.

## Validaciones pendientes
Por tratarse de Seguridad y Salud en el Trabajo, antes de utilizarlo como capacitación oficial el área responsable de SST debe validar: criterios ergonómicos aplicables, procedimientos de comunicación, pausas, métodos de manipulación, ayudas disponibles, terminología corporativa y cualquier límite o requisito interno/legal aplicable. El contenido actual evita establecer valores o procedimientos oficiales no proporcionados.

## Privacidad
No solicita nombre, correo ni otros datos personales. No usa cookies, almacenamiento local ni backend. La puntuación existe solo en memoria durante la sesión y desaparece al recargar o cerrar la página.

## Accesibilidad
Controles nativos de teclado, foco visible, contraste, `aria-live` en la retroalimentación, mensajes que no dependen solo del color, diseño adaptable y compatibilidad con `prefers-reduced-motion`.

## Pruebas ejecutadas
Se comprobaron automáticamente: existencia de los cuatro archivos; enlaces exactos a `style.css` y `script.js`; sintaxis JavaScript con `node --check`; presencia de 6 retos y elementos para inicio, progreso, retroalimentación, resultado y reinicio. No se realizó una auditoría formal WCAG ni una prueba con lector de pantalla/navegadores múltiples.

## Limitaciones
La aplicación no registra resultados ni genera certificados. Los escenarios son ejemplos pedagógicos generales y necesitan validación interna de SST antes de uso oficial.

## Tres aprendizajes clave
1. Revisar el puesto y la tarea antes de normalizar una postura o esfuerzo incómodo.
2. Reducir alcances y exposiciones innecesarias siguiendo las condiciones autorizadas del proceso.
3. Comunicar molestias o dudas y recurrir a las pautas y ayudas definidas por SST.

## Compromiso de transferencia
Identifica una mejora ergonómica aplicable hoy a tu puesto y, si implica modificar procesos, equipos o condiciones de trabajo, consúltala con el responsable correspondiente.
